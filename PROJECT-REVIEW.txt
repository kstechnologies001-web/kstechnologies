IMPORTANT BEFORE LIVE USE
- The ZIP cannot install Cloudflare/Supabase secrets, bind Workers AI, configure Auth redirect URLs, or deploy to the user's accounts.
- Run supabase/schema.sql if the wider customer portal schema is not already installed.
- Run supabase/website-table-permissions.sql to create/secure the contact_messages and faq_entries tables and apply the least-privilege grants/policies. Existing tables are not dropped.
- Add SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, SUPABASE_SECRET_KEY, PAYSTACK_SECRET_KEY and PAYSTACK_WEBHOOK_SECRET in Cloudflare Pages settings. Save SUPABASE_SECRET_KEY, PAYSTACK_SECRET_KEY and PAYSTACK_WEBHOOK_SECRET as encrypted secrets. SUPABASE_SECRET_KEY must be a Supabase Secret key, never the browser Publishable key.
- Add the Workers AI binding named AI to the Pages project for /api/chat.
- Configure Supabase Auth Site URL/Redirect URLs and test registration, email confirmation, login, password reset and logout.
- Configure Paystack test secret and webhook before attempting test payments.
- Promote the intended administrator account with the SQL in START-HERE-KST-BACKEND.md.
- Live end-to-end tests require the actual Cloudflare/Supabase/Paystack accounts and cannot be verified from the ZIP alone.
