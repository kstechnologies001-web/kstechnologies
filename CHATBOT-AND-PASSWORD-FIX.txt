KST WEBSITE — CHATBOT AND PASSWORD VISIBILITY FIX
================================================

WHAT WAS FIXED
- The floating KST chatbot launcher remains small, circular and champagne-gold.
- Chatbot styles now live in css/chatbot.css instead of being injected from the JavaScript file.
- Chatbot script references now use paths that work from the website root and from a preview opened inside the extracted website folder.
- The chatbot resolves config.js and /api/chat from the location of its own script, avoiding the old hard-coded root path problem.
- The chatbot is included across the site's existing HTML pages.
- The customer Login and Register password fields now have Show/Hide controls. The Register tab is part of account/login.html; account/register.html redirects to it.

HOW TO PREVIEW ON YOUR PHONE
1. Extract this ZIP.
2. Open the extracted folder named KST_Midnight_Black_Champagne_Gold_Chatbot_Fixed.
3. Start your local web server from inside that folder when possible.
4. Open the homepage (index.html) through the local server, not by opening the file directly.
5. Look at the bottom-right corner for the circular KST button.
6. Tap KST to open the chat window. Tap × to close it; the KST circle returns.

You can also serve the parent folder and open the extracted folder's URL. The corrected chatbot paths support that nested preview too.

IMPORTANT ABOUT AI REPLIES
The circular button and chat window can display without the live AI service being deployed. For actual AI answers online, deploy the Cloudflare Pages Functions and configure the Workers AI binding named exactly AI. The chatbot sends messages to /api/chat. Local static previews do not run the Cloudflare backend unless you use the Cloudflare Pages local development command with its required bindings.

PASSWORD CONTROLS
On the client account page, select Log in or Register. Tap Show beside the password field to reveal it; the same control changes to Hide. Tap Hide to mask it again.

DESIGN PRESERVATION
The existing Midnight Black + Champagne Gold design and the original website page layouts have been preserved. Only the chatbot loading/styling and password visibility controls were changed.
